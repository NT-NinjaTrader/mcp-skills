# Code of Conduct

## The standard

This project trades on trust. Hold to the same standard here.

Do this:

- Treat every person with respect.
- Assume that the other person acts in good faith.
- Accept a technical disagreement as a technical disagreement.
- Give a correction about the work, and not about the person.
- Respect a decision after the maintainers make it.

Do not do this:

- Do not insult, demean, or harass a person.
- Do not make a comment about a personal characteristic. This covers age, body
  size, disability, ethnicity, gender, nationality, personal appearance, race,
  religion, and sexual identity.
- Do not post sexual content, or make a sexual advance.
- Do not publish private information about a person without their permission.
- Do not spam an issue or a pull request.
- Do not promote a trading product, a signal service, or a paid group.

## Financial conduct

This project touches real money, so two more rules apply:

- Do not give financial advice in an issue, a pull request, or a review. These
  skills are software. They are not advice.
- Do not post a claim about a return, a win rate, or a profit. Such a claim
  invites a reader to trade on it.

## Scope

This code applies in every project space. It covers an issue, a pull request, a review, a commit message, and a discussion.

It also applies when a person represents this project in a public space.

## Report a problem

Report a breach of this code through GitHub private vulnerability reporting. Go to the Security tab, and select **Report a vulnerability**. That is the private channel this repository has.

Give the following:

1. What happened.
2. Where it happened. A link is best.
3. When it happened.

The maintainers read every report. The maintainers answer the reporter.

Do not open a public issue to report a breach. A public report can make the problem worse for the person it affects.

Report a security vulnerability through the same channel, and see [`SECURITY.md`](SECURITY.md).

## What the maintainers do

The maintainers decide the response. A response fits the breach:

| Breach | Response |
|---|---|
| A first, minor breach | A private warning, and a request to correct the comment |
| A repeated breach, or one that continues after a warning | A temporary block from the project spaces |
| Harassment, a threat, or a sustained pattern | A permanent block |

The maintainers may edit or delete a comment, an issue, or a pull request that breaks this code. The maintainers say why when they do.

A person who disagrees with a decision may answer the report thread once. The maintainers then make the final decision.

## Enforcement of this code

The maintainers hold to this code too. A maintainer who breaks it answers to the other maintainers.

For an account question, go to <https://ninjatrader.com/support/>. For help with the platform, go to the same page. This code covers conduct in this repository, and it cannot reach your account.
