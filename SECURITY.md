# Security policy

## Report a vulnerability

Report a security vulnerability through GitHub private vulnerability reporting.
Go to the Security tab and select **Report a vulnerability**.

Do not open a public issue for a security report.
A private report lets the maintainers assess and fix the problem before it becomes public knowledge.

The maintainers read every private report and answer the reporter.
This policy states no response-time commitment.

## Not a security problem?

Do not use the security channel for a product question.
For help with an account, a login, funding, the platform, or an order, go to <https://ninjatrader.com/support/>.
For a defect in a skill or in a tool the skill calls, open a GitHub issue instead.
